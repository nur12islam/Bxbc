# BXBC – Bharatpur Xerox & Book Centre

A responsive notebook-inspired website for BXBC, built with HTML, CSS and JavaScript.

## Main products and services
- Exercise books and notebooks
- Pens and writing supplies
- School stationery and office supplies
- Text-based PDF printouts only (no image files or image-to-PDF printouts)
- Limited Xerox and photocopy
- WhatsApp and click-to-call links
- Google Maps directions and embedded map
- Responsive mobile navigation and reduced-motion support

## Project structure
- `index.html` — homepage
- `about.html`, `services.html`, `brands.html`, `gallery.html`, `reviews.html`, `faq.html`, `contact.html`
- `privacy.html`, `terms.html`, `thank-you.html`, `404.html`
- `assets/css/notebook.css` — notebook-style layout and responsive styling
- `assets/js/notebook.js` — navigation, opening status and scroll reveal
- `assets/images/` — shop, service and brand images
- `assets/favicon/` — website icons
